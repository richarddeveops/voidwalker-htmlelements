Container and Void Elements

Container element

A container element has an opening tag, content, and a closing tag.

<p>This is a paragraph.</p>

This is a paragraph.

Void element

A void element has no child content and does not have a closing tag.

<img src="photo.jpg" alt="A description of the photo">

Attributes

Attributes add information to an opening tag. For example, an image uses src for its file and alt for its text alternative.

Elements should be nested in the correct order, and a label's for value should match a form control's id.
