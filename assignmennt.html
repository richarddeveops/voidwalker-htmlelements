Block and Inline Element Examples

This assignment lists 20 elements that commonly display as blocks and 20 that commonly display inline. CSS can change an element's display.

Common block elements

These elements normally start on a new line and use the available width.

  1. <address> contact information
  2. <article> self-contained content
  3. <aside> related content
  4. <blockquote> a long quotation
  5. <div> a general-purpose group
  6. <dl> a description list
  7. <fieldset> a group of form controls
  8. <figure> self-contained media or illustration
  9. <form> a group of form controls
  10. <h1> the main page heading
  11. <header> introductory content
  12. <hr> a thematic break
  13. <main> the page's main content
  14. <nav> a group of navigation links
  15. <ol> an ordered list
  16. <p> a paragraph
  17. <pre> preformatted text
  18. <section> a thematic section
  19. <table> tabular data
  20. <ul> an unordered list

Common inline elements

These elements normally flow within a line of text.

  1. <a href> a link; href gives its destination
  2. <b> attention drawn to text
  3. <br> a line break
  4. <code> a short code sample
  5. <em> emphasized text
  6. <i> text in an alternate voice
  7. <img src alt> an image; src and alt describe it
  8. <input type> a form field; type sets its kind
  9. <label for> a field label; for matches the field's id
  10. <mark> highlighted text
  11. <q> a short quotation
  12. <s> text that is no longer accurate
  13. <small> side comments or fine print
  14. <span> a general-purpose inline group
  15. <strong> important text
  16. <sub> subscript
  17. <sup> superscript
  18. <time datetime> a date or time; datetime gives its machine-readable value
  19. <u> text with a non-text annotation
  20. <var> a variable name
